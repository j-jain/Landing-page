AZURE PRODUCTION ARCHITECTURE (proposed; DENSO mandate = all runtime on Azure)
------------------------------------------------------------------------------
- Hosting: Azure App Service (Linux, Node 20) OR Azure Container Apps (full Next.js parity with
  Vercel; the /api/lead route works as-is). [Azure Static Web Apps is possible but would require
  static export + moving the API into an Azure Function.]
- Edge/security: Azure Front Door (Premium for WAF) — CDN, TLS, routing, DDoS.
- Media: Azure Blob Storage (Hot) for videos/posters, served via Front Door.
- Data: Azure Cosmos DB (serverless) or Table Storage for leads.
- Email: Azure Communication Services (Email).
- Secrets: Azure Key Vault. Monitoring: Application Insights + Log Analytics.
- DNS: Azure DNS. Region: Central India (data residency for lead PII).
- CI/CD: GitHub Actions / Azure Pipelines -> the chosen Azure host.
- COMPLIANCE: Vercel is NON-Azure -> treat it as preview/staging only; production must be Azure.
  The Pexels videos are the one non-Azure runtime dependency and are resolved by the Blob migration
  (no exception needed once done).
