GOLDEN RULE LEARNED THE HARD WAY
--------------------------------
Never keep a Next.js project inside a OneDrive/Dropbox-synced folder. It breaks the dev
server (reload loop) and corrupts the build (.next). See 04-MISTAKES-AND-LESSONS.txt.
